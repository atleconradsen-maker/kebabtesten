# Kebabtesten

Kebab og brød, scoret 1–10. Total = 80 % kebab + 20 % brød.
Kebabscore = snitt av kjøtt, saus, fyll, porsjon og pris/verdi.

Dataene hentes fra Google-regnearket «Kebabtesten – tester» (Drive-mappen «Kebabtesten»).

## Legge inn en test
Én rad per testperson. Første rad i en test har alt om kebaben (dato, sted, hva, servert som,
pris, sterkhet, brødtype). De neste testpersonene trenger bare navn og scorer – Sted kan stå tomt,
da hører raden til testen over. Testpersonene kan være forskjellige fra gang til gang.

Bilder: last opp til Drive-mappen «Bilder», Del → Kopier lenke, lim inn i «Bilde kebab» / «Bilde sjappa».
